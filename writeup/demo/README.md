# Demo recording

**Watch:** https://youtu.be/L6lZ9rOHJQY (YouTube, unlisted). Offline copy: [`pharmassist-demo.mp4`](pharmassist-demo.mp4).

A 10-minute 33-second walkthrough of the
live application at https://pharmassist.aishwaryabhanage.com, recorded on 2026-10-19. It shows: sign-in as
pharmacy staff; questions from [../Example_Questions_Expected_vs_Assistant_Answers.pdf](../Example_Questions_Expected_vs_Assistant_Answers.pdf)
answered with citations that open the source page (the HbA1c target range, the medication class for heart
failure with the program-assumption banner); rating an answer with a reason; the admin pages (overview with
questions, latency, spend and the semantic cache; Documents with a new PDF uploaded, indexed and listed with
its version; Users with roles); and the evaluation table of every run, with the production configuration
ranked against the alternatives.

The MP4 is the original screen recording re-encoded (H.264, 1920 px wide, about 20 MB) so that GitHub plays it
in the browser when the file is opened; the original `.mov` (3024×1894, 232 MB) is kept outside the repository.

Screenshots taken by script against production on 2026-10-18 are in [../evidence/screenshots/](../evidence/screenshots/).
