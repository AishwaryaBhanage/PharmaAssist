PharmAssist · design

Every answer is cited, or it is exactly “No answer found in knowledge base”

One pharmacy operations question at a time, answered from the 11 public VA, Medicare Part D and NY Medicaid documents in the corpus. Accuracy 0.85 with 0 incorrect, groundedness 0.937, 21.4 s at p95 against 30 s, $0.110 per fresh question. Nothing below is estimated unless it says so.

6 · AI usage

The AI wrote the code; the human set scope, made the cost calls and ran the real thing

What the AI did

Claude Code (Claude Fable 5.1) as an orchestrator over parallel subagents in git worktrees: seven streams for v2 (data, llm, api, cache, ingest, frontend, infra) against shared contracts, then an integration pass. It wrote the code, tests, documentation, prompts and the evaluation harness.

What the human did

Set the scope; made the product and cost decisions (instance sizing, reranker off after seeing the numbers, the 0.90 threshold, the warm worker); reviewed every merge; ran the admin-only AWS and DNS steps.

What failed: the frontend and its test mocks shared a wrong health path, so tests passed while the live banner was wrong; the ingestion image lacked a dependency that only showed in the real container; five IAM gaps, one per deploy attempt. Each was found by running the real thing, not by review.

Return the matched child and let the model read_page for the rest: about 4× fewer input tokens. Then answer short coverage questions (Q11, Q12: under 2,000 input tokens) with the fallback model at effort low, 2.5× cheaper per token. Config plus a tool-result formatter.

The median question makes 2–3 sequential model turns. Run the search and both drug lookups on the original question before the first model call and put the results in the first prompt, so two-turn questions need one. Q11 (one turn) took 5.2 s against the 10.8 s median.

Architecture

The retrieval unit is the child chunk; the delivery unit is the parent section

Two kinds of content do not fit chunks

Formulary and PDL rows live in table_rows because drug-specific PA questions ranked generic PA prose above the row that answered them. Figures are inventoried from the PDF, interpreted once by a vision model into boxes and labelled arrows, checked against an independent OCR, and chunked as complete decision paths (reports/parsing/VISUAL_EXTRACTION.md); the visual set scores 1.0 because of it.

Preprocessing facts that shaped the design

  • The VA/DoD algorithm flowcharts are raster images (diabetes pp. 21–22, opioids pp. 25–27) no text extractor sees; the appendices print the same algorithms as text.
  • The NYRx manual's table of contents is broken, so headings are found by bold font plus “N.0” numbering.
  • NY PDL rows come from a fixed-column extractor that reads the 6.96 pt effective-date markers by font size (src/pharmassist/tables/ny_pdl.py); all 1,522 rows were checked against the PDF (tests/test_ny_pdl.py).

Data model and search

  • documents and document_versions (status queued → parsing → chunking → embedding → active), chunks, parents, figures, table_rows, ingestion_jobs, plus users, conversations, feedback and usage (src/pharmassist/store/pg.py).
  • Activating a new version supersedes the old one in the same transaction and bumps the generation that invalidates the cache.
  • Each search runs the agent's query and the original question concurrently and fuses them: +0.075 accuracy (EVALUATION.md §3.1, Oct 17 row).
  • Not built: summaries, concept articles, a graph. These questions are answered by specific sections and rows; a generated layer is one more thing to keep grounded.

Quality

Three hallucination detectors: one in the prompt, one in code, the rest offline

How groundedness is measured

Offline: a Claude Opus judge splits each answer into claims and checks each against the text of the cited pages and rows only, three passes, median taken (src/pharmassist/eval/judge.py; docs/PROMPTS.md §2). Reported as supported claims / claims (0.937) and as Safe, answers with zero unsupported claims (17/20). DeepEval (judge claude-sonnet-5-5) ranks the versions the same way and scores 0.98–1.0 everywhere because it penalises contradiction, not missing support; the harness numbers are the strict ones. Regression testing is §5; two answer-side improvements were measured under its rule and left off because accuracy did not rise (EVALUATION.md §4.5).

Continuous improvement

Ratings, admin review and eval failure classes feed the corpus and the golden set

Found in the corpus, not yet surfaced in the UI: the NY PDL gives the opioid PA threshold as “≥ 90 MME” in class rows and “> 90 MME” in the fentanyl row; the 2020 and 2025 VA guides disagree on continuing a DPP-4 when prandial insulin starts (Q02 applies the rule and names it). Code: app/admin.py, frontend/src/pages/admin/ConversationsPage.tsx, DELETE /api/v1/admin/documents/{id}/index.
