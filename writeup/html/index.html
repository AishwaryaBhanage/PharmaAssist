Demo

One command runs it from public images; one more builds it from this checkout

From Docker Hub (no build, no Node, no Python)

# from the repo root
cp .env.example .env   # put your OPENAI_API_KEY in it (ANTHROPIC_API_KEY too for the fallback model)
docker compose -f deploy/docker-compose.yml \
  -f deploy/prebuilt.override.yml --env-file .env up

Pulls abhanage/pharmassist-v2-web and abhanage/pharmassist-v2-ingest (Intel and Apple Silicon), starts Postgres 16 + pgvector, Valkey, a local SQS and S3, the API and the ingestion worker, and seeds the 11 documents with no model spend. Open http://localhost:8000; demo accounts are listed in SOLUTION.md.

From this checkout

cp .env.example .env
docker compose up --build   # compose.yaml; a few minutes the first time

Fresh answers use your API key, about $0.11 each; repeats are free. docker compose down -v removes the data. Step by step: solution.html.
