PharmAssist · the solution

One Docker command, no Node or Python, and the corpus is answerable

A web app for pharmacy staff: one operational question in, one cited answer out in about 15 seconds of reading, grounded only in 11 public VA, Medicare Part D and NY Medicaid documents. Staff ask and rate; admins see every conversation, upload, re-index or remove documents, and watch spend. Deployed on AWS at pharmassist.aishwaryabhanage.com (not kept running); runs locally from public images.

Accounts and cost

Open http://localhost:8000. Two demo accounts are seeded, admin@pharmassist.local (Ask + Admin: conversations, ratings, documents, jobs, users, cache, spend) and staff1@pharmassist.local (Ask + own conversations); their passwords are in SOLUTION.md. Fresh answers use your API key, about $0.11 each (reports/evals/v2_2026-10-18_0903/summary.md); repeats are free. To build from this checkout instead: docker compose up --build (compose.yaml; a few minutes the first time).

How it works

One question vector serves the cache and the search; the citation check decides the answer

Answering

The agent answers only from returned text, states the program assumption, names the precedence rule it applied, and declines non-pharmacy questions (out_of_scope, docs/PROMPTS.md). Code: src/pharmassist/agent/, src/pharmassist/cache/valkey.py, app/answer_service.py.

Retrieval

Small chunks (350 tokens, with heading path) are matched; the enclosing section (≤ 1,500 tokens) is read. Formulary and PDL rows are exact lookups; flowcharts printed as images were interpreted once by a vision model and checked against OCR (reports/parsing/VISUAL_EXTRACTION.md). Why: DESIGN.md “Architecture”.

Citations

Each citation is a document title plus page, opening the stored PDF at that page (evidence/screenshots/citation-source.png); a page with an interpreted figure links the crop (frontend/src/components/ask/CitationList.tsx, FigureNote.tsx).

Ingestion

An upload is answerable 5 s after submission with the warm worker

Measured on production, 2026-10-18: remove-from-index returned 200 with counts, the document's question then returned the no-answer sentence, re-indexing took 5 s and it was answerable again (production run, admin API). Code: src/pharmassist/ingest/, app/admin.py; limits in config.yaml uploads.

Operations

One CloudFormation stack in us-east-1: static IPs in front, a warm worker behind

Configuration

config.yaml holds what experiments change: llm (primary and fallback models, prices, retries, embeddings), search, cache (threshold 0.90, TTL), auth, uploads, limits_v2 (10/min and 100/day per user, 500/day global, $10/day spend) and tracing_v2. .env holds keys and URLs; never commit it.

Authentication and roles

Signup creates a staff account; admins promote or deactivate users. Access tokens are 15-minute JWTs; the refresh token is a rotating HttpOnly cookie, revoked on logout and on any role change (app/auth.py, config.yaml auth). Set APP_INSECURE_COOKIES=1 on plain http.

Tracing

With LANGSMITH_TRACING=true each answer is one LangSmith run (project pharmassist) with question, answer, citations, provider, model, fallback, cached flag, latency, cost and tokens, and child runs per model call, tool call and retrieval. LANGSMITH_CONTENT_MODE=metadata keeps content out.

Worker.venv/bin/python scripts/ingest_worker.py (--once drains the queue and exits)

Evaluation.venv/bin/python scripts/run_eval.py --label my_change --deepeval (paid; method and all runs in EVALUATION.md §6)
